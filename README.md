# Winnipeg Urban Taxonomy Viewer

An interactive web dashboard for exploring the hierarchical classification of Winnipeg's urban fabric. Built with React, MapLibre GL, D3, and GSAP.

## Features

- **Interactive Map** — MapLibre GL map with morphotope and building layers, hover tooltips, click-to-inspect properties
- **Dual Clustering Approaches** — Switch between Fixed Count (2-128 clusters) and Percentile-based (data-driven thresholds) dendrogram cuts
- **Hierarchy Tree** — D3 dendrogram with three layout modes:
  - **Circular** — radial dendrogram
  - **Vertical** — top-down tree
  - **Geographic** — leaf nodes positioned at morphotope centroids, mirroring the city's spatial layout
- **GSAP Fisheye Lens** — hover over the hierarchy to distort and magnify nodes for easy selection, with adjustable radius and distortion
- **Level Control** — view the tree at different depths (3-10 levels, full tree, or simplified by cluster)
- **Layer Management** — reorder layers, toggle visibility, sync levels and color ramps between morphotopes and buildings
- **Multi-Cluster Filtering** — click legend items or tree nodes to filter the map; click branch nodes to select entire subtrees
- **Zoom to Cluster** — double-click any legend item or tree leaf to fly the map to that cluster's extent
- **Resizable Panels** — drag panel edges to resize; GSAP-animated open/close with toggle tabs
- **Dark/Light Theme** — system-aware with manual toggle
- **18+ Color Ramps** — Spectral, Viridis, Plasma, Bold, Pastel, and more via chroma-js

## Tech Stack

- **React 19** + TypeScript
- **MapLibre GL** — vector map rendering
- **D3** — hierarchy layout and rendering
- **GSAP** — fisheye animation and panel transitions
- **Mantine 9** — UI components
- **Chroma.js** — color ramp generation
- **FlatGeobuf** — efficient streaming of large geospatial datasets
- **Vite** — build tooling

## Getting Started

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:5173`.

### Data

Place these files in `public/data/`:

| File | Description |
|------|-------------|
| `morphotopes.fgb` | Morphotope polygons with cluster levels |
| `buildings.fgb` | Building footprints with height, population, cluster levels |
| `hierarchy_tree.json` | D3-compatible dendrogram with pruned variants |
| `taxonomy_hierarchy.json` | Cluster summary statistics per level |

These are generated by the companion pipeline repository [`urban_taxonomy`](../urban_taxonomy/) using `scripts/update_viewer_data.py`.
